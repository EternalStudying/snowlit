Project integration:
The original React / React Three Fiber shell was not copied. The cloud texture + shader
visual logic was ported into Snowlit's existing WeatherController -> CloudSkySystem ->
CloudSkyLayer architecture as an internal weather atmosphere effect. Demo-only controls
and the original demo background gradient are not part of the production integration.
